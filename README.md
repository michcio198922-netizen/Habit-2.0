# Nawyki 2.0

Aplikacja Android do śledzenia dobrych i złych nawyków.

## Co nowego
- czarne tło / dark mode
- dodawanie, edycja i usuwanie nawyków
- oznaczanie Sukces / Porażka
- licznik serii dni
- szybki podgląd ostatnich 7 dni
- statystyki 7 i 30 dni
- kalendarz miesiąca
- codzienne przypomnienia o wybranej godzinie
- zapis danych lokalnie w telefonie

## Jak zbudować APK bez Android Studio
1. Wgraj projekt na GitHub.
2. Wejdź w **Actions**.
3. Zaczekaj na workflow **Zbuduj APK**.
4. Pobierz artifact **Nawyki-APK**.
5. W środku znajdziesz `app-debug.apk`.
